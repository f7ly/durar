# DURAR — درر الكنوز العربية
## Salla Twilight Starter / Overlay

هذه الحزمة هي نقطة البداية لتحويل التصميم البصري المعتمد إلى ثيم فعلي لمنصة سلة.

### طريقة الاستخدام الصحيحة
1. أنشئ ثيم جديد من بوابة شركاء سلة أو Salla CLI بحيث يبدأ من Theme Raed الرسمي.
2. انسخ محتويات مجلد `src/` من هذه الحزمة فوق مشروع Theme Raed.
3. أضف استيراد ملف `durar-custom.scss` داخل ملف الستايل الرئيسي في المشروع.
4. أضف استيراد `durar-custom.js` داخل ملف JavaScript الرئيسي أو حمّله من `master.twig`.
5. استخدم ملف `src/views/pages/index.twig` الموجود هنا كنسخة الصفحة الرئيسية.
6. شغّل:
   `npm install`
   ثم:
   `salla theme preview`
7. عدّل صور البنرات وروابط الأقسام من الملفات الموجودة في:
   `src/views/components/home/`

> مهم: هذه الحزمة لا تستبدل Theme Raed بالكامل؛ بل تُركّب فوقه حتى نحافظ على مكونات سلة الأساسية مثل السلة، تسجيل الدخول، الدفع، التصفية، المنتجات والـ Web Components.

### الهوية
- فحمي: `#1F1B17`
- شامبين: `#D4AF7C`
- بيج هادئ: `#C9B89B`
- كريمي: `#F7F3EA`
- أبيض: `#FFFFFF`

### الملفات الرئيسية
- `durar-custom.scss`: تصميم الهوية والاستجابة للجوال.
- `durar-custom.js`: تفاعلات خفيفة.
- `index.twig`: تركيب الصفحة الرئيسية.
- `durar-hero.twig`: البنر الرئيسي.
- `durar-category-circles.twig`: دوائر الأقسام.
- `durar-promo-grid.twig`: بنرات الهدايا والمباخر.
- `durar-collections.twig`: المجموعات.
- `twilight.durar.settings.json`: إعدادات مقترحة لدمجها داخل `twilight.json`.

### المرحلة التالية
بعد تركيب هذه النسخة على Theme Raed وربطها بمتجر تجريبي، يتم ضبط أسماء selectors ومكونات المنتجات بحسب النسخة الحالية للثيم ثم إكمال صفحة المنتج، التصنيفات، السلة والفوتر 1:1.
